# Mosques Management System

## Description
A desktop application built with Python (`tkinter`) and SQLite to manage and track mosque records, including details such as mosque type, address, coordinates, and imam names.

## Features
* **Graphical User Interface (GUI):** Built using Tkinter with structured grid layouts and list boxes.
* **Database Management:** Uses SQLite (`sqlite3`) for persistent data storage.
* **CRUD Operations:** Supports displaying, searching, adding, and deleting mosque entries.

## Tech Stack
* **Language:** Python 3
* **GUI Framework:** Tkinter
* **Database:** SQLite3
